## CM-GUI: User-Friendly application of the CM Pipeline

This repo contains the transcript for a paper that details the software implementation of a Graphical User Interface for the CM Pipeline. 

The GUI paper can be found at [paper.md](https://github.com/alfredjynx/JOSS-GUI-Transcript/blob/main/paper.md). The references and bibliography of the paper are at [paper.bib](https://github.com/alfredjynx/JOSS-GUI-Transcript/blob/main/paper.bib).

There are two papers detailing the CM Pipeline. The [original one](https://arxiv.org/abs/2303.02813) (Park et al.) goes over the main reasons for the creation of the tool and what it can do. The [second one](https://joss.theoj.org/papers/10.21105/joss.06073) (Ramavarapu et al.) is an addition to the original software.

The main repo for the CM Pìpeline can be found [here](https://github.com/illinois-or-research-analytics/cm_pipeline), and [this](https://illinois-or-research-analytics.github.io/cm_pipeline/) is the link to the CM Pipeline documentation. The main repo for the CM GUI is [this one](https://github.com/alfredjynx/GUI-CM). There, you can find the entire source code for the GUI as well as install and run instructions.
